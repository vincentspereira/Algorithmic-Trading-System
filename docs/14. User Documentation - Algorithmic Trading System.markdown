## Trading Strategies

The system supports creating, testing, and deploying trading strategies using both no-code and code-based tools.

### No-Code Strategy Builder

Perfect for users without coding experience:

1. Go to **"Strategies" > "New Strategy" > "No-Code Builder"**.
2. Drag indicators (e.g., Moving Average, RSI) from the left panel to the canvas.
3. Set parameters (e.g., period = 50 for a moving average).
4. Define conditions and actions (e.g., "Buy when 50-day MA crosses above 200-day MA").
5. Click **"Save"** and name your strategy.

### Python Studio

For advanced users who prefer coding:

1. Navigate to **"Strategies" > "New Strategy" > "Python Studio"**.
2. Access a cloud-hosted Jupyter notebook environment.
3. Write your strategy using Python and pre-installed libraries (e.g., TA-Lib, pandas-ta).
4. Test your code with sample data.

**Example: Simple Moving Average Crossover Strategy**

```python
import pandas as pd
from quantconnect.algorithm import QCAlgorithm

class SMACrossover(QCAlgorithm):
    def Initialize(self):
        self.SetStartDate(2020, 1, 1)
        self.SetEndDate(2021, 1, 1)
        self.SetCash(100000)
        self.AddEquity("SPY", Resolution.Daily)
        self.fast = self.SMA("SPY", 50)
        self.slow = self.SMA("SPY", 200)

    def OnData(self, data):
        if self.fast.Current.Value > self.slow.Current.Value:
            self.SetHoldings("SPY", 1.0)
        else:
            self.SetHoldings("SPY", 0.0)
```

### Backtesting

Evaluate your strategy’s performance:

1. Select a strategy from the **"Strategies"** menu.
2. Click **"Backtest"**.
3. Set the date range, initial capital, and trading mode (paper or live).
4. Run the simulation.
5. Review results, including:
   - Equity curve
   - Sharpe Ratio
   - Maximum drawdown
   - Total return

**Tip**: Optimize your strategy by adjusting parameters based on backtest results (see [Analytics and Reports](#analytics-and-reports)).

## Options Trading

Trade options with specialized tools and features.

### Overview

Options are contracts giving the right, but not the obligation, to buy or sell an asset at a set price before an expiration date. The system supports both basic and complex options strategies.

### Creating Strategies

1. Navigate to **"Strategies" > "New Strategy" > "Options Strategy"**.
2. Choose a template (e.g., covered call, iron condor).
3. Customize legs, strike prices, and expiration dates.
4. Save your strategy.

### Tools

- **Greeks Calculator**: Assess risk with Delta, Gamma, Theta, and Vega.
- **Payoff Diagrams**: Visualize potential profit/loss scenarios.
- **Volatility Suite**: Analyze implied and historical volatility surfaces.

**Tutorial: Setting Up a Covered Call**

1. Select a stock you own (e.g., "AAPL").
2. Choose an expiration date and strike price for the call option.
3. Use the payoff diagram to evaluate outcomes.
4. Place the order to sell the call.
